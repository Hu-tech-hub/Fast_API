# 🏃 FastAPI란?

**"API를 빠르게 만들 수 있게 도와주는 Python 웹 프레임워크"**  
(이름 그대로 FAST + API)

---

# 📚 한 줄 요약

> "FastAPI는 파이썬으로 웹 서버를 만들 때 빠르고 쉽게 API(인터넷 서비스 통신 규칙)를 만드는 도구야."

---

# ⚡ FastAPI의 특징

| 특징 | 설명 |
|:---|:---|
| **빠르다** | 서버 응답 속도가 엄청 빠르다. (Starlette라는 고성능 엔진 기반) |
| **비동기 지원** | async/await 덕분에 동시에 많은 요청을 처리할 수 있다. |
| **자동 문서 생성** | 코드를 작성하면 자동으로 API 문서를 만들어준다 (Swagger, ReDoc). |
| **타입 힌트 사용** | Python의 타입 표기를 적극적으로 활용해서 코드가 더 깔끔하고 안전하다. |
| **사용하기 쉽다** | Flask처럼 간단한데 더 현대적이고 강력한 기능을 갖고 있다. |

---

# 🏛️ FastAPI를 왜 쓸까?

- **빠르게 개발**할 수 있다.
- **코드가 명확**하다. (타입 힌트를 쓰니까, 에러가 줄어든다)
- **자동으로 문서**가 생긴다. (개발자가 설명서를 따로 안 만들어도 됨)
- **비동기**가 쉬워서 대규모 서비스(예: 채팅, 게임 서버)도 만들 수 있다.

---

# 🛠️ FastAPI로 할 수 있는 일

- 웹 API 서버 만들기 (예: 쇼핑몰 서버, 로그인 서버)
- AI 모델 서빙하기 (예: 딥러닝 모델 웹으로 연결)
- 실시간 서비스 (예: 실시간 알림 서버)
- 채팅 서버 만들기 (Socket도 지원함)

# 🎯 간단한 흐름

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def hello():
    return {"message": "Hello, FastAPI!"}
```

1. FastAPI 앱을 만든다 → `app = FastAPI()`
2. 주소(`/`)를 정한다 → `@app.get("/")`
3. 오면 어떤 응답을 줄지 정의한다 → `return {...}`
4. 서버를 실행하면 웹에서 API 사용 가능

# 🚀 로컬 서버 실행 방법

### ✅ 1. uvicorn 설치
```bash
pip install fastapi uvicorn
```

### ✅ 2. Python 파일 저장 (예: `main.py`)

```python
# main.py
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}
```

### ✅ 3. uvicorn으로 실행
```bash
uvicorn basic.main:app --port=8000 --reload
```

- `main`: 파일 이름 (main.py)
- `app`: FastAPI 인스턴스 이름 (`app = FastAPI()`)
- `--reload`: 코드 수정 시 자동 재시작 (개발용)

### ✅ 4. 접속
- 브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)
- 자동 생성 문서:  
  - Swagger UI → [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)  
  - ReDoc → [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

# 📖 정리

| 질문 | 답변 |
|:---|:---|
| FastAPI가 뭐야? | Python으로 빠르고 쉽게 API 서버를 만드는 프레임워크야. |
| 장점은 뭐야? | 빠름, 비동기, 자동 문서, 타입 힌트, 쓰기 쉬움. |
