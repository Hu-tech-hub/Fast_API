# 📚 FastAPI에서 사용하는 4가지 요청방식 설명

---

FastAPI는 사용자가 서버에 **요청(Request)** 을 보내면 그에 맞는 **응답(Response)** 을 해주는 시스템이다.  
요청에는 여러 종류가 있는데, 대표적으로 **GET**, **POST**, **PUT**, **DELETE** 이렇게 4가지가 있다.  
각 요청은 하는 일이 다르다.

---

## 1. GET 요청 — "가져와 줘!"

GET은 **"정보를 가져오고 싶을 때"** 사용하는 요청이다.  
사용자는 서버에 "나에게 이 정보를 보여줘!" 하고 요청을 보내고, 서버는 그 정보를 찾아서 보내준다.

예를 들면:
- 쇼핑몰에서 상품 목록을 보고 싶을 때
- 블로그 글을 읽고 싶을 때

**FastAPI에서는 이렇게 만든다:**

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

---

## 2. POST 요청 — "새로운 걸 보내줄게!"

POST는 **"새로운 정보를 서버에 보내고 싶을 때"** 사용하는 요청이다.  
사용자는 서버에 "여기 새 글이야, 저장해줘!" 하고 데이터를 보낸다. 서버는 그걸 받아서 새로 저장한다.

예를 들면:
- 회원가입할 때 이름과 비밀번호를 보내기
- 새 글을 작성해서 서버에 등록하기

**FastAPI에서는 이렇게 만든다:**

```python
@app.post("/items/")
async def create_item(item: Item):
    return {"item_name": item.name}
```

---

## 3. PUT 요청 — "기존 것을 고쳐줄게!"

PUT은 **"이미 있는 정보를 수정하고 싶을 때"** 사용하는 요청이다.  
사용자는 서버에 "이 정보 좀 바꿔줘!" 하고 고쳐진 데이터를 보낸다. 서버는 기존 것을 수정한다.

예를 들면:
- 프로필 사진을 변경할 때
- 상품 가격을 수정할 때

**FastAPI에서는 이렇게 만든다:**

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    return {"item_id": item_id, "item_name": item.name}
```

---

## 4. DELETE 요청 — "기존 것을 지워줘!"

DELETE는 **"이미 있는 정보를 삭제하고 싶을 때"** 사용하는 요청이다.  
사용자는 서버에 "이거 필요 없어, 지워줘!" 하고 요청을 보낸다. 서버는 그 정보를 삭제한다.

예를 들면:
- 내가 쓴 게시글을 삭제할 때
- 장바구니에서 상품을 뺄 때

**FastAPI에서는 이렇게 만든다:**

```python
@app.delete("/items/{item_id}")
async def delete_item(item_id: int):
    return {"message": "아이템 삭제 완료"}
```

---

# 🏛️ 전체 요약표

| 요청 종류 | 하는 일 | 예시 |
|:---|:---|:---|
| GET | 정보를 가져온다 | 상품 목록 보기 |
| POST | 새로운 정보를 추가한다 | 새 글 등록하기 |
| PUT | 기존 정보를 수정한다 | 회원정보 수정 |
| DELETE | 기존 정보를 삭제한다 | 게시글 삭제 |
