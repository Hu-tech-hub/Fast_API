# 🧠 정적(static) vs 동적(dynamic) 서버 – 심화 설명

## 1. 📦 **정적 서버 (Static Server)**

### ✅ 정의
정적 서버는 **요청된 리소스를 있는 그대로 반환**하는 서버입니다.  
서버는 미리 만들어진 파일(HTML, CSS, JS, 이미지 등)을 **가공 없이 직접 전송**합니다.

### ✅ 특징
- 파일 기반: `index.html`, `style.css`처럼 파일이 실제 존재
- 처리 로직 없음: 요청에 따라 로직을 실행하지 않고, 그냥 **파일을 찾아서 응답**
- 빠르고 가벼움
- 데이터베이스(DB) 필요 없음
- 보통 CDN(Content Delivery Network)이나 정적 웹 호스팅(Netlify, GitHub Pages 등)에서 사용

### ✅ 예시 흐름
```
[브라우저] → GET /about.html
[서버] → 디렉토리에서 about.html 찾아서 그대로 전송
```

---

## 2. ⚙️ **동적 서버 (Dynamic Server)**

### ✅ 정의
동적 서버는 요청이 들어오면 **서버 내에서 로직을 실행해 결과를 생성하고**, 그 결과를 **동적으로 응답**합니다. 즉, 요청마다 다른 결과가 나올 수 있습니다.

### ✅ 특징
- 요청을 처리하기 위한 **프로그램(코드)**이 실행됨
- 입력값에 따라 서로 다른 응답 생성
- 데이터베이스와 연동하는 경우가 대부분
- 느릴 수 있지만 **맞춤형 응답** 제공 가능
- 보통 웹 프레임워크(FastAPI, Django, Flask 등)를 통해 구현

### ✅ 예시 흐름
```http
GET /items/42
→ 서버 내부 코드 실행: item_id=42에 해당하는 정보를 DB에서 조회
→ 조회 결과를 JSON 또는 HTML로 가공하여 응답
```

---

## 3. 📚 기술적 차이 비교

| 구분 | 정적 서버 | 동적 서버 |
|------|-----------|------------|
| 응답 생성 방식 | 디스크에 있는 파일을 그대로 응답 | 코드가 실행되어 결과 생성 |
| 속도 | 빠름 (파일 I/O) | 상대적으로 느림 (로직 + DB) |
| 서버 역할 | 파일 전달자 | 계산자 / 변환자 |
| 상태 의존성 | 없음 (모든 사용자에게 동일한 응답) | 있음 (사용자/요청에 따라 다름) |
| 예시 | 이미지, HTML, JS, CSS | 사용자 정보, 상품 목록, 댓글 기능 등 |

## 4. 🔍 FastAPI에서의 적용

### 🔸 정적 파일 서빙
FastAPI는 정적 파일도 서빙할 수 있음.

```python
from fastapi.staticfiles import StaticFiles

app.mount("/static", StaticFiles(directory="static"), name="static")
```

→ `http://localhost:8000/static/logo.png` 요청 시,  
`static/logo.png` 파일을 **그대로 응답**함 (정적 처리)

---

### 🔸 동적 HTML 렌더링 (Jinja2)
템플릿 파일(`.html`)을 불러와, 파이썬 객체의 내용을 삽입하여 HTML을 만들어냄.

```python
@app.get("/user/{name}", response_class=HTMLResponse)
async def greet(request: Request, name: str):
    return templates.TemplateResponse("greet.html", {
        "request": request,
        "name": name
    })
```

→ 사용자마다 **다른 name 값**이 들어가므로, HTML도 사용자마다 다르게 생성됨.  
이게 바로 **동적 처리**.

## 5. 🧩 예시 비교 (같은 HTML이지만 정적 vs 동적)

### ✅ 정적 HTML (static/about.html)
```html
<h1>회사 소개</h1>
<p>이 페이지는 고정입니다.</p>
```

### ✅ 동적 HTML (템플릿)
```html
<h1>{{ name }}님 환영합니다!</h1>
<p>오늘도 좋은 하루 보내세요.</p>
```

템플릿에 `name="상엽"`이 들어가면 →  
`<h1>상엽님 환영합니다!</h1>` 로 만들어져서 응답됨

## ✅ 요약

| 핵심 질문 | 정적 처리 | 동적 처리 |
|-----------|------------|-------------|
| 서버가 응답을 만들기 위해 **생각을 하냐?** | ❌ (그냥 꺼내줌) | ✅ (생각하고 만들어줌) |
| 사용자마다 다른 결과가 나오냐? | ❌ 항상 같음 | ✅ 요청에 따라 다름 |
| 템플릿 엔진, DB 연동 필요한가? | ❌ 필요 없음 | ✅ 필수적 |
| 속도 | 매우 빠름 | 비교적 느림 (하지만 유연함) |
