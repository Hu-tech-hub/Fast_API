## ✅ APIRouter란?

> `APIRouter`는 **FastAPI 앱 안에서 라우팅(API 경로)만 따로 관리하는 객체**입니다.  
> 간단히 말해, **라우트(경로 + 처리함수)의 “모음집”**입니다.

---

## 🎯 왜 쓰는가?

### ❌ FastAPI를 그s냥 쓰면:
```python
# main.py

@app.get("/users")
def get_users(): ...

@app.post("/items")
def create_item(): ...
```

모든 API가 한 파일에 몰림.  
→ 프로젝트 커지면 **헬 게이트** 열림. 협업도 어렵고 유지보수도 힘듦.

---

### ✅ APIRouter를 쓰면:
```python
# users.py
router = APIRouter()

@router.get("/users")
def get_users(): ...
```

```python
# main.py
from users import router as user_router
app.include_router(user_router)
```

→ `users` 관련 API만 따로 `users.py`에서 관리.  
→ **구조가 깔끔**, 확장성 좋음, 테스트도 쉬움.

---

## 📦 구조 비유

> FastAPI 앱은 **자동차 본체**,  
> APIRouter는 **기능별로 따로 만든 부품**입니다.

- `/users` 기능은 `users_router`
- `/items` 기능은 `items_router`
- `main.py`는 이것들을 조립해서 완성된 자동차(앱)를 만드는 곳

---

## ⚙ 핵심 개념 요약

| 개념 | 설명 |
|------|------|
| `APIRouter()` | API 엔드포인트를 담는 모듈 |
| `@router.get()` | 해당 모듈에 경로 등록 |
| `app.include_router()` | FastAPI 앱에 라우터 모듈을 탑재 |
| `prefix="/users"` | 이 라우터의 모든 경로 앞에 `/users` 붙임 |
| `tags=["Users"]` | Swagger 문서에서 그룹화 |

---

## ✍ 한 줄 요약

> `APIRouter`는 API 경로를 **기능별로 정리하는 객체**,  
> `include_router()`는 그것들을 FastAPI 앱에 **조립**하는 명령.
